# Design notes (follow anthropics/skills frontend-design)
Source skill: https://github.com/anthropics/skills/tree/main/skills/frontend-design

Concept: "the quote pad". A creator about to name a price.
- Color: paper #f2f5f3, ink #142b24, pine #1f5c47 (primary), highlighter #f4f06a (only on the answer price), slate #5e6f68, rule #d5ded9.
- Type: Bricolage Grotesque (display, narrow width 75-90), Public Sans (body), tabular numbers.
- One loud thing: the hero sentence calculator ("I make __ about __ and each one gets about __ views. Ask for $X to $Y"), with the price highlighter-marked. Everything else quiet.
- Avoided defaults: no dark hero + orange accent, no stat strip, no eyebrow labels, no middle-dot meta, no arrows on buttons, no card kit.
- Tried and rejected: v2 (dark hero, orange, stats grid, Inter) looked templated.
